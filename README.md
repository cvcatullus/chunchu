# 연세춘추 지면 아카이브 (1995–2002)

연세춘추 200개 호(1995–2002) 지면 이미지와 문자 인식(OCR) 본문을 기사 단위로 검색·열람하는 정적 사이트입니다.

- **전체 첫 화면·전체 연도 검색:** https://cvcatullus.github.io/chunchu/
- **연도별:** [1995](https://cvcatullus.github.io/chunchu-1995/) · [1996](https://cvcatullus.github.io/chunchu-1996/) · [1997](https://cvcatullus.github.io/chunchu-1997/) · [1998](https://cvcatullus.github.io/chunchu-1998/) · [1999](https://cvcatullus.github.io/chunchu-1999/) · [2000](https://cvcatullus.github.io/chunchu-2000/) · [2001](https://cvcatullus.github.io/chunchu-2001/) · [2002](https://cvcatullus.github.io/chunchu-2002/)

열람하려면 키워드를 넣어야 합니다.

## 만든 방법

- 원본: 연세대학교 도서관 디지털 컬렉션의 호별 지면 PDF와 기사 목록
- 지면 나누기: AI 레이아웃 모델 PP-DocLayoutV3 (PaddlePaddle, Apache-2.0)
- 문자 인식: macOS Vision
- 기사 묶기: 도서관 기사 목록 + AI 읽기 순서 기반 규칙(목록에 없는 기사는 '자동 추출'로 표시)
